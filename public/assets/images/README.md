# Fotografias

Coloque aqui as fotos do restaurante (JPG/WebP, ~1600px de largura, otimizadas).
Use somente imagens próprias ou com licença comercial adequada.

Depois referencie o nome do arquivo em `src/data/photos.js` e `src/data/menu.js`
(campo `photo`), por exemplo: `photo: 'moqueca.webp'`.
Campos vazios exibem uma ilustração padrão.
